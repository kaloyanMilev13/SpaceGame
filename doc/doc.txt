MAIN IDEA:

Single player 2D "8 bit" game where the user controls a space ship and the main goal is to dodge and destroy asteroids coming towards it. The ship has a health bar and takes a couple of asteroid hits to be destroyed. Over time the game gets progressively harder with asteroid becoming more faster and harder to destroy. They also start to spawn more frequently and create tighter spaces between them. The ship would also upgrade during the game, with upgrades/rewards/collectables spawning in between the asteroids.

Other than the main gameplay window, there would also be a menu for adjusting Brightness, SFX and Music. There would also be a small but varied collection of ships, with each one having a different design and different shooting mechanic. Ships will be unlockable either by achieving a higher score or b y collecting coins which spawn as a type of a reward.




TECHNOLOGIES:

The game will be written in C using the raylib library. I won't use a game engine.

I chose C, because I have previous experience with C and Embedded C, that's why I feel like I can complete this game in the duration of 4 weeks. 

I chose raylib, because it seems like a beginner friendly version of the SDL library and since I haven't done anything like that before, I think a limited but easier to learn library would be better for this project.

I'm also using Vim as a main code editor. I would not use an IDE, because I want to challenge myself and actually learn how to properly use Vim. I find it very minimalistic and that provides creativity for me.
